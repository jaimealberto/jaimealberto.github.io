Mkv, cortar

Comando completo:

ffmpeg -i input.mkv -c copy -map 0 -segment_time 01:00:00 -f segment output%03d.mkv

  • ffmpeg herramienta que permite procesar videos, convertir entre formatos, extraer audio, cortar, unir, etc.

  • -i: Archivo de entrada que se va a procesar.

  • -c copy: Esta opción indica que se debe copiar el flujo de video y audio tal cual está en el archivo de entrada, sin re-encodear (sin procesar o modificar).

  • Esto hace que la operación sea más rápida, ya que solo se copian los datos del archivo de entrada a los archivos de salida, sin necesidad de procesamiento adicional.

  • -map 0: mapea todo el contenido del archivo de entrada (el 0 hace referencia al primer archivo de entrada), lo que significa que se copiarán todas las pistas (video, audio, subtítulos, etc.) desde el archivo original.

  • Esto es útil cuando hay múltiples flujos (como subtítulos o múltiples pistas de audio) y deseas copiarlos todos.

  • -segment_time 01:00:00: Define la duración de cada segmento de video.

  • El archivo se dividirá en fragmentos de 60 minutos (3600 segundos).

  • -f segment: Este parámetro le indica a FFmpeg que utilice un formato de salida segmentado.

  • output%03d.mkv: Archivo de salida.

  • %03d es un componente de formato indica a que numere los archivos de salida con tres dígitos.
