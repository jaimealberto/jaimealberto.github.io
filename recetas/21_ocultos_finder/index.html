Ocultos Finder MacOs

JaimeAlberto

Con Finder abierto y en ventana activa pulsamos:

command (⌘) + mayúsculas (⇧) + signo punto (.)

o desde el terminal:

Activar:

$defaults write com.apple.Finder AppleShowAllFiles true
$killall Finder

Desactivar:

$defaults write com.apple.Finder AppleShowAllFiles false
$killall Finder
